NOTES

How it works

CSV format

One daily row per store and SKU, including zero-sales days. Use closing stock and total discounts. Returns assume the goods can be resold.

date, store, sku, category, units, unit_price, unit_cost, discount, returns, inventory, lead_days

Use one currency per file. The selector changes the label, not the amounts.

Forecasts and limits

Forecasts use the last 28 days. Backtests predict up to 28 historical observations using earlier data only. WAPE measures total absolute error relative to sales.

Order targets cover lead time plus buffer days using the latest stock record. Missing dates and stockouts can distort forecasts.
